## 模块：Q2 业绩表 (q2-table)

> ⚠️ 此模块为受保护模块，含合计行与利润公式，整个模块不可在面板编辑。

| 字段 | 来源 | 是否受保护 | 说明 |
|---|---|---|---|
| columns 表头 | 手动定义 | 是 | 固定列：月份/收入/成本/利润 |
| rows 数据行 | 财务月报 Q2 | 是 | 4-6月实际数据 |
| totalRow 合计行 | 计算得出 | 是 | 由 rows 各数值列求和 |

**计算公式**：
- 合计行 = 各月份收入/成本/利润分别求和
- 利润列（每行）= 收入 - 成本

**数据更新流程**：
1. 从财务系统导出月度报表
2. 编辑 `config.js` 中 `rows.value` 数组
3. `totalRow` 会自动重新计算
4. 更新 `data-source.md` 中的来源日期
